- Cross-Site Scripting (XSS):
	- Attackers inject malicious javascript code in a web page.

- SQL Injection (SQLi):
	-  Attackers manipulate user input to inject SQL code into the application database to retrieve sensitive information or even get users access without credentials.

- Cross-Site Request Forgery (CSRF):
	- Attackers trick authenticated users into unkowingly perfoming actions on a web app, such as changingg account details.

- Server-Side Request Forgery (SSRF):
	- Attackers use SSRF to make requests from the server to internal resources or external networks, potentially leading to data theft or unauthorized access.
