- First Line
	- HTTP version followed by the status code of the response.
		- 200 - OK
		- 301  - Moved
		- 400 - Bad Request
		- 401 - Unauthorized
		- 403 - Forbidden
		- 404 - Not Found
		- 500 - Internal Server Error

- Response Headers
	- Similar to request headers, response headers provide additional information about the response like:
		- Content-Type (The media type: text/html,....)
		- Content-Length
		- Set-Cookie
		- Cache-Control

- Reponse Body
	- Contains the actual content of the response.
