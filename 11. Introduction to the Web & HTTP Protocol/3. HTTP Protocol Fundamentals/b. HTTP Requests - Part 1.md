- Request Line:
	- The request line is the first line of an HTTP request and contains the followings three components:
		- HTTP Method
		- URL
		- HTTP Version

- Request Headers
	- Headers provide additional information about the request:
		- User-Agent
		- Host (Hostname of the server)
		- Accept (The media type the client can handle in the response)
		- Authorization (Credentials for authentication)
		- Cookie

- Request Body (Optional)
	- Some HTTP methods (POST or PUT) include a request body where data is sent to the server, typically JSON or form data format.
