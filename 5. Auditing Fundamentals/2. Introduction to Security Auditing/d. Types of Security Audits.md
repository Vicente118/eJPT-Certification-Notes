
\- Types based on scope, methodology and aspects of the organization they focus on

---

1. Internal audits : Conducted by the organization's internal audit team or security professionals to evaluate the effectiveness of internal controls and compliance with policies.

2. External audits: Performed by independent third-party auditors to provide an unbiased evaluation of the organization’s security measures and compliance with external standards.

3. Focus on verifying that the organization complies with specific regulatory requirements and industry standards (e.g., GDPR, HIPAA, PCI DSS).

4. Technical audits: Focus on assessing the technical aspects of the organization’s IT infrastructure, including hardware, software, and network configurations.

5. Network audits: Assess the security of the organization’s network infrastructure, including routers, switches, firewalls, and other network devices.

6. Application audits: Evaluate the security of software applications, focusing on code quality, input validation, authentication mechanisms, and data handling.
