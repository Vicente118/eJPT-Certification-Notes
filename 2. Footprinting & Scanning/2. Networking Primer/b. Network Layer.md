Internet Protocol : IP (Layer 3)
   - IPv4
   - IPv6
   - IP enables communication between devices on different networks by providing a standardized way to identify and locate hosts.

Internet Control Message Protocol : ICMP (Layer 3)
- Used for error reporting and diagnostics. ICMP messages includes ping, traceroute, and varios error messages. 

Dynamic Host Configuration Protocol : DHCP 
- DHCP is often used in conjuction with IP to dynamically assign IP addresses to devices on a network, simplfying the process of network configurations.
